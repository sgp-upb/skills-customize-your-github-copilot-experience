
# 📘 Assignment: Hangman Game Challenge

## 🎯 Objective

Build the classic Hangman word-guessing game using Python strings, loops, conditional logic, and user input.

## 📝 Tasks

### 🛠️ Game Setup and Word Selection

#### Description
Create a Hangman game that chooses a secret word from a predefined list and prepares the game state.

#### Requirements
Completed program should:

- Randomly select a word from a predefined list.
- Initialize the hidden word display with underscores for each letter.
- Track letters guessed by the player.
- Set a limit for incorrect guesses.

### 🛠️ Guess Handling and Game Feedback

#### Description
Implement the main gameplay loop to accept guesses, update progress, and provide feedback.

#### Requirements
Completed program should:

- Accept letter guesses from the user.
- Reveal correct letters in the progress display.
- Show incorrect guesses and remaining attempts.
- End when the word is fully guessed or attempts are exhausted.
- Display a win message if the player guesses the word.
- Display a lose message if the player runs out of attempts.
